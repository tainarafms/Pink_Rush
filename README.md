# PINK RUSH

> Jogo web arcade desenvolvido com HTML5, CSS3 e JavaScript puro.

## Objetivo do Jogo
Acelere em PINK RUSH! Um jogo arcade eletrizante desenvolvido em HTML, CSS e JavaScript. Desvie de obstáculos, colete raios de energia e encare uma pista neon desafiadora onde a velocidade aumenta a cada nível!

## Regras e Como Jogar
- **Movimentação**: Utilize as setas direcionais esquerda/direita (`[◄] [►]`) ou as teclas `[A]` e `[D]`.
- **Pontuação**: Cada raio azul coletado concede `+100 pontos`.
- **Níveis**: A cada 500 pontos, o nível da partida aumenta, acelerando a velocidade e o fluxo de obstáculos na pista.
- **Fim de Jogo**: A colisão com qualquer carro inimigo encerra a partida imediatamente.

## Tecnologias Utilizadas
- **HTML5** (Estruturação e marcação)
- **CSS3** (Estilização visual, animações e efeitos neon)
- **JavaScript** (Lógica de jogo, tratamento de eventos e manipulação do DOM)
